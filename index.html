Project Overview

A predictive analytics project using publicly available F1 data

Business Context

Formula 1 is one of the most data-intensive sports in the world. This project investigates whether a driver's qualifying position combined with constructor championship standings can reliably predict podium finishes - with applications in broadcast strategy, fantasy sports, and team performance benchmarking.

Hypothesis

H₀: Qualifying position and constructor standings have no significant relationship with podium finish probability.

H₁: Qualifying position and constructor standings are statistically significant predictors of podium finish.

Data Source

Jolpica F1 API

Race results, qualifying positions, and constructor standings were extracted via the Jolpica API - a community-maintained source of comprehensive F1 data from 1950 to present.

Data Pipeline
  • Race results: 2010–2024 via REST API
  • Qualifying positions: matched by race ID and driver ID
  • Constructor standings: rolling form indicator per race
  • Train/test split: by season to prevent data leakage

Key Findings

What the analysis revealed

Qualifying position is highly predictive

Drivers starting from pole position convert to a podium finish significantly more often than any other grid position.

Constructor form amplifies the effect

Strong constructor championship standing further increases podium probability, independent of qualifying position.

Model performance

Logistic Regression outperformed Random Forest for this use case. While Random Forest achieved higher accuracy (0.854 vs 0.815) and precision (0.513 vs 0.445), Logistic Regression achieved a substantially higher recall of 0.926 — correctly identifying 9 in 10 actual podium finishes. Given the broadcast and team analytics use case, minimising missed podiums is the priority, making Logistic Regression the recommended model with a best F1 score of 0.601.

Methodology

Technical approach and ethical considerations

Models Used

Classification Approach

A binary classification target was engineered: podium finish (positions 1–3 = 1, all others = 0). Two models were trained and compared:

  • Logistic Regression - interpretable baseline model
  • Random Forest - captures non-linear relationships, provides feature importance

Models were evaluated using accuracy, precision, recall, and F1 score - the latter prioritised given class imbalance (only 3 podium finishes per race).

Ethical Considerations

Bias, Privacy & Fairness

  • Bias: Dataset is skewed toward dominant eras (Mercedes 2014–2021). Season-based train/test split and era awareness mitigate this.
  • Privacy: All data is publicly available professional sporting performance. No personal or sensitive data involved.
  • Fairness: The model is descriptive and predictive only - not used to make decisions about individuals.
